# DNS-Switchtool / DNS 切换工具

一个简单好用的 Windows DNS 切换工具，帮你快速切换网络配置。
A simple and easy-to-use DNS switching tool for Windows to quickly switch network configurations.

---

## 功能特点 / Features

- **一键切换 / One-click Switching**：预设多组 DNS 方案，双击即可切换，无需繁琐配置。
  Preset multiple DNS schemes, double-click to switch, no tedious configuration required.
- **轻量级 / Lightweight**：纯绿色软件，无需安装，解压即用。
  Pure portable software, no installation required, just unzip and use.
- **简单直观 / Simple & Intuitive**：界面简洁，操作逻辑清晰。
  Clean interface and clear operation logic.

---

## 使用方法 / How to Use

1. 确保你的电脑已安装 Python（建议 3.8+）。
   Ensure your computer has Python installed (Recommended 3.8+).
2. 将本仓库克隆到本地：
   Clone this repository to your local machine:
   ```bash
   git clone https://github.com/Liyun2613/DNS-Switchtool.git
   ```
3. 运行主程序：
   Run the main program:
   ```bash
   python Switchtool.py
   ```
